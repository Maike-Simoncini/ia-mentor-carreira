# IA Mentor de Carreira 🚀

O **IA Mentor de Carreira** é um projeto focado em **Engenharia de Prompts** (Prompt Engineering) para transformar o Google Gemini em um mentor especializado em tecnologia. O sistema utiliza uma abordagem de múltiplos agentes para diagnosticar o perfil do usuário e traçar um plano de ação concreto para evolução na área tech.

## 📝 Descrição

Este projeto utiliza inteligência artificial para ajudar pessoas a descobrirem caminhos profissionais em tecnologia, identificando interesses, sugerindo áreas de atuação e indicando habilidades importantes para o desenvolvimento da carreira.

## 🤖 Estrutura dos Agentes

O fluxo de mentoria é dividido em duas etapas fundamentais:

### 1. AGENTE 1 - Entrevistador de Carreira 📋
Este agente atua na fase de diagnóstico. Ele realiza uma entrevista estruturada para entender:
- Interesses técnicos (Back-end, Front-end, Dados, Cibersegurança, etc).
- Nível de experiência atual e formação acadêmica.
- Objetivos de curto e longo prazo.
- Preferências de resolução de problemas e estilo de trabalho.

### 2. AGENTE 2 - Planejador de Carreiras 📅
Após a entrevista, este agente processa o histórico e entrega um plano estratégico:
- **Roadmap de Estudos:** Sequência lógica de tecnologias para aprender.
- **Sugestão de Projetos:** Ideias de projetos práticos para fortalecer o portfólio.
- **Hard & Soft Skills:** Lista de habilidades essenciais para a trilha escolhida.

---

## 🚀 Como Utilizar

Para ter sua sessão de mentoria no [Google Gemini](https://gemini.google.com):

1. **Inicie a Entrevista:** Abra o arquivo `agente_1_entrevistador.md`, copie o prompt e cole no chat do Gemini. Responda às perguntas feitas.
2. **Gere seu Plano:** Após finalizar a conversa com o primeiro agente, abra o arquivo `agente_2_planejador.md`, copie o prompt e cole no mesmo chat. A IA gerará o seu roadmap personalizado baseado nas suas respostas anteriores.
